# Security Program

This document defines the minimum security program for enterprise readiness.

## Required controls
- Asset inventory and data-flow diagrams.
- Risk register reviewed quarterly and after material changes.
- Least-privilege access and MFA for workforce accounts.
- Joiner, mover, leaver process for employees and contractors.
- Secrets stored only in managed secret stores.
- Peer review and automated checks for production changes.
- Centralized audit events with retention and export.
- Incident response, backup/restore, and disaster recovery testing.
- Vendor due diligence and subprocessors register.
- Security awareness training at onboarding and annually.

## Review cadence
- Daily: monitoring and alert review.
- Weekly: dependency and vulnerability review.
- Monthly: access review, restore test, and security metrics.
- Quarterly: risk review and privileged-access review.
- Annually: penetration test and disaster-recovery exercise.

## Claims policy
Do not claim SOC 2 certification until an independent examination is completed and a report is issued.
