# AI Firewall Dashboard

Enterprise-grade monitoring dashboard for AI Firewall security platform.

## Features

- **Real-time Security Monitoring** - Live threat detection and alerts
- **Interactive Analytics** - Visualize request patterns and security events
- **Audit Log Viewer** - Search and filter historical requests
- **Security Controls** - Configure threat detection thresholds
- **Webhook Management** - Set up alert notifications

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm start

# Build for production
npm run build

# Run tests
npm test
